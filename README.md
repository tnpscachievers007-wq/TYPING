# Typing Drill: Tamil and English

One page with three trainers:

- **Tamil99 Keys**: letters, pulli, grantha, clusters, words and phrases on the Tamil99 layout.
- **Typewriting Lessons**: lessons 1 to 9 (words, sentences, paragraphs) for exam practice.
- **English**: home row to full sentences, with a finger map and WPM stats.

Progress is saved in your browser (localStorage). Each trainer keeps separate stats. Theme is shared.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole app |
| `manifest.webmanifest` | Lets phones install it to the home screen |
| `icon.svg` | App icon and favicon |
| `README.md` | This file |

## Publish on GitHub Pages

1. Create a new repository and upload all four files to the root.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
